# 07. 감각 연출 타임라인 / 실기기 QA

## 1. 붓기 연출의 단일 진실 공급원

붓기 시간은 `src/components/pourTiming.ts`에서만 계산한다.

```text
튜브 이동  →  기울기  →  액체 흐름  →  착지  →  복귀/커밋
```

- 이동 층 수가 많을수록 스트림 지속시간과 굵기가 증가한다.
- `PourAnimation`, 튜브 액체 높이 미리보기, 사운드, 햅틱은 같은 진행도를 사용한다.
- 논리 상태는 연출 종료 시 한 번만 커밋하지만, 화면에서는 흐르는 동안 출발량과 도착량이 연속적으로 변한다.
- 애니메이션 콜백 누락에 대비한 안전 타이머는 계속 유지한다.

## 2. 클리어 시퀀스

논리적인 `cleared`와 결과 모달 노출을 분리한다.

```text
마지막 착지
  → 완성 튜브 순차 펄스
  → 보드 중앙 링/스파클
  → 결과 카드
  → 별 순차 등장음/햅틱
  → 코인 카운트업
  → 버튼 활성화
```

클래식 레벨 증가는 즉시 저장하지만, 사용자 레벨 변경으로 게임 초기화 효과가 다시 실행되지 않도록 한다.

## 3. ASMR 감각 방

- 접촉 루프는 랜덤 위치에서 페이드인한다.
- 손을 떼면 즉시 자르지 않고 페이드아웃한다.
- 접촉 중에는 BGM을 덕킹해 재질음을 앞으로 가져온다.
- 파티클 RAF는 입자가 존재할 때만 실행하고 약 30fps로 제한한다.
- 터치 절대좌표를 플레이 영역 좌표로 변환해 파티클이 손가락 위치에서 발생하도록 한다.
- 재질 표면 단서: 물 파문, 슬라임 기포, 폼 거품, 스펀지 기공, 로션 광택.

## 4. 실기기 합격 기준

- [ ] 1층/4층 붓기의 시간·굵기·촉감 차이가 명확하다.
- [ ] 액체 줄기가 이동 중인 튜브 입구보다 먼저 나타나지 않는다.
- [ ] 스트림 종료 직전 출발/대상 액체 높이가 튀지 않는다.
- [ ] 마지막 튜브 완성 연출을 결과 모달이 가리지 않는다.
- [ ] 클리어 멜로디, 별 음, 코인 음이 한꺼번에 겹치지 않는다.
- [ ] 클리어 도중 Undo/Reset으로 상태가 깨지지 않는다.
- [ ] ASMR 첫 터치에 눈에 띄는 디코드 지연이 없다.
- [ ] 손을 뗄 때 루프가 클릭음처럼 갑자기 잘리지 않는다.
- [ ] ASMR 유휴 상태에서 파티클 React 렌더가 지속되지 않는다.
- [ ] Android 중급기에서 게임/ASMR 입력 지연이 체감되지 않는다.
- [ ] 웹 빌드에서 네이티브 전용 Skia 스트림 대신 웹 폴백이 정상 표시된다.
